# Тихолесье — памятка для Claude

Прочитай этот файл и `ИСТОРИЯ.md` целиком, прежде чем что-то менять. В `ИСТОРИЯ.md` — все версии, что просил Андрей и что ему потом не понравилось; в `тз/` — заказы дословно.

## 1. Что за игра и где живёт

- «Тихолесье» — спокойная вертикальная прыгалка по мшистым кочкам ночного леса. Автор — Андрей. Всё в одном файле `index.html`: разметка, CSS, шрифты в base64, весь JS. Графика рисуется кодом на canvas, звук синтезируется (Web Audio). Внешних библиотек нет.
- Репозиторий `plush-reiko/tiholesye`, ветка `main`. GitHub Pages раздаёт корень: https://plush-reiko.github.io/tiholesye/
- Андрей играет на iPhone 16 Pro Max с экрана «Домой», без интернета. Офлайн держит `sw.js` (service worker): при первом открытии кладёт файлы в кэш и дальше берёт их оттуда.
- **Как обновляется на айфоне.** Имя кэша в `sw.js` (`tiholesye-xxxxxxxxxxxx`) — это версия. Новое имя → телефон при следующем открытии с интернетом скачает новую версию; после полного закрытия и запуска она заработает. Пока имя прежнее, телефон показывает старую версию, даже если `index.html` на сервере новый.

| Файл | Что внутри |
| --- | --- |
| `index.html` | Вся игра |
| `sw.js` | Офлайн-кэш: имя кэша и список `FILES` |
| `manifest.webmanifest` | Имя, цвета, иконки приложения |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | Иконки (512 — ещё и maskable: важное в центральных 80%) |
| `ИСТОРИЯ.md` | Все версии: просьбы, решения, проверки, что не понравилось |
| `тз/` | Заказы Андрея дословно |
| `проверка/` | Скрипты на Playwright: `shots.py` (снимки и листы), `tests.py` (автопроверки), `skin.py` (облики крупно по одному), `trails.py` (следы в забеге), `icons.py` (рисует три иконки) |

## 2. Как работать

1. Правь `index.html` прямо в репозитории. Старые исходники на ПК Андрея (`D:\iphone_offline_game`, `src/` + `build.mjs`) устарели с 19.11: сборку из них не восстанавливай, код бери только отсюда.
2. Стиль кода как в файле: комментарии по-русски, короткие помощники, без внешних библиотек и файлов. Всё, кроме иконок, — внутри `index.html`. Шрифты (строки 5–10, base64) не читай.
3. Проверяй в браузере с экраном iPhone 16 Pro Max: Playwright + Chromium, окно 440×956, `deviceScaleFactor` 3, `isMobile`, `hasTouch`. Раздавай по http: `python3 -m http.server 8765 --bind 127.0.0.1 --directory .` (иначе не работает service worker).
   - `python3 проверка/shots.py <папка>` — снимки экранов (меню, лавка, памятка; ещё раз в окне высотой 700) и листы: облики, силуэты, состояния, платформы, ворчуны, находки, облики на небе пяти зон, забег в пяти зонах.
   - `python3 проверка/tests.py [разделы через запятую]` — автопроверки: `gift coins ghost leaf beasts migration skins texts bot lite speed offline` (бот проходит лес до 7 000 м, «Экономно», скорость при процессоре ×4, офлайн при выключенном сервере).
   - Для листа «до/после» обликов, свежего кода переноса из старой версии и проверки скорости нужна старая версия: `git archive 8fd511c | tar -x -C старая` (облики 21.11, схема v2), раздай её на порту 8766 и передай `TL_OLD_URL=http://127.0.0.1:8766/index.html`.
   - `python3 проверка/skin.py tihohodka,opyata,rosyanka лист.png 4` — облики крупно: цвет, силуэт, моргание, без заряда, кадры взмаха, подъём, спуск, лицом влево, игровой размер. `python3 проверка/trails.py следы.png [lite]` — следы всех обликов в забеге. `python3 проверка/icons.py .` — перерисовать иконки.
   - На Windows: вместо `python3` — `python`; в папке репозитория `git config core.autocrlf false` (иначе файлы получат CRLF и отпечаток кэша не совпадёт с тем, что раздаёт GitHub); `trails.py` пишет кадр в `/tmp/_t.png` — запускай копию с другой папкой.
   - Открывай снимки сам и сравнивай с заказом. «Код работает» — не доказательство: главный риск — картинка, похожая на сделанную ИИ. В консоли должно быть ноль ошибок.
4. Отладка: `window.__tl` отдаёт `game`, `P`, `run`, `save`, `Art`, `Snd`, `UI`, `SKINS`, `SKIN_ART`, `startRun`, `update`, `render`, `genUpTo`, `migrateV1`, `applySave`, `exportCode`, `importCode`, `afterLoad`, `checkUnlocks`, `emitTrail`, `skinById` и другое. На нём держатся тесты и снимки — всё новое добавляй туда.
5. **Выдача.** После правок — новое имя кэша (команда ниже), коммит в `main` с сообщением по-русски, запись в `ИСТОРИЯ.md`. Pages обновится за 1–3 минуты. Нет доступа на запись — пришли Андрею изменённые файлы и инструкцию: репозиторий → Add file → Upload files → перетащить → Commit changes.

```bash
node -e "const fs=require('fs'),h=require('crypto').createHash('sha256');for(const f of ['icon-180.png','icon-192.png','icon-512.png','index.html','manifest.webmanifest'])h.update(f).update(fs.readFileSync(f));const v=h.digest('hex').slice(0,12);fs.writeFileSync('sw.js',fs.readFileSync('sw.js','utf8').replace(/tiholesye-[0-9a-f]{12}/,'tiholesye-'+v));console.log(v)"
```

Имя кэша = `tiholesye-` + первые 12 знаков sha256 от файлов игры по алфавиту. Список `FILES` в `sw.js` не меняй; `CLAUDE.md`, `ИСТОРИЯ.md`, `тз/`, `проверка/` туда не добавляй.

## 3. Как работать с Андреем

- По-русски, простыми словами. Честно и без лести: если что-то вышло плохо или не доделано — так и сказать.
- Подробно, чтобы не пришлось переспрашивать.
- Каждую команду терминала, которую он запускает сам, разбирать по словам: что делает каждая часть.
- Тестирует на iPhone 16 Pro Max, разрабатывает на ПК с Windows.
- Не спойлерить книги, игры и фильмы.
- Как обновить игру на айфоне (повторять в отчёте): включить интернет, открыть игру, подождать ~15 с, закрыть полностью (смахнуть из списка приложений), открыть снова. Иконка на «Домой» может обновиться не сразу: iOS её кэширует. Удалять приложение не советовать — пропадёт сохранение.

**Вкус Андрея**
- Игра не должна выглядеть сделанной нейросетью. Что под капотом, игроку всё равно, но внешне он не должен об этом даже задуматься.
- Минимализм, но не примитив: перегруженный экран плохо (v1), экран из одних простейших фигур тоже плохо (v2).
- Цвета мира: фиолетовый, синий, голубой — все три видны, перевес в синий. Перекос в фиолетовый не нравится.
- Светящиеся грибы — часть леса, фон и украшение. Платформы — мшистые кочки.
- Тёплый светящийся цвет в лесу один — светлячки (`#ffe3a0`). С 21.11 облики могут быть тёплыми и контрастными, но «под луной».
- Ничего из Doodle Jump и других игр: ни персонажей, ни названий, ни узнаваемых решений.
- Интерфейс «бумага и чернила» и дизайн кочек v4 ему очень нравятся: без просьбы не трогать.
- Подсказки не должны быть навязчивыми: дорожка «+N» и стайки светлячков ему не понравились.
- Интерфейс и тексты по-русски, с правильными окончаниями у чисел (`plural`).

**Выводы на будущее:** просьбу «в лесу есть X» не превращать в «всё из X»; «проще» не значит «из кругов»; знакомый приём из известной игры читается как копия; шаблон «тело + шапка» и одно милое лицо на всех выдают ИИ сильнее всего.

## 4. Принципы дизайна

Главное: игрок не должен даже задуматься, что игру нарисовал ИИ. Минимализм — это мало объектов и мало шума, а не бедные формы.

1. **Нарисовано человеком.** Формы — из вручную расставленных точек, а не из кругов, эллипсов и звёзд. Асимметрия осознанная, у каждого существа свой характер.
2. **«Ночная аппликация».** Плоские заливки без градиентов; объём — вторым тоном с жёсткой границей, не больше трёх тонов на деталь; края чуть неровные, «ножницами»; жёсткая тень, как под бумагой в интерфейсе.
3. **Палитра.** Ночь: синий, голубой, фиолетовый с перевесом в синий. Светлячки — единственный тёплый светящийся цвет леса.
4. **Ничего из чужих игр.** **У каждого существа своё движение** — одна «пульсация» на всё тоже штамп.

**ИИ-штампы, которых не должно быть нигде:** одно «милое» лицо на всех (овальные глаза с двумя бликами, розовый румянец); четырёхлучевые искры и пятиконечные звёзды как украшение; фигуры из идеальных кругов и полукругов (луна-диск, облака-полукруги, кроны-кружки, островки-треугольники); зеркальная симметрия живых существ; один и тот же блик слева сверху и тень-серп справа снизу у всего; свечение на всём, фиолетовые градиенты, полупрозрачные пятна вместо форм; пастельная сиренево-голубая гамма у всех персонажей; «база + шапка» — одно тело на всех.

**Как рисовать облики** (раздел 3 ТЗ 24.11, «Бестиарий Тихолесья»):
1. Облик — диковина именно этого леса (сказка, поверье, чудо природы, ожившая вещь), а не обычный зверь. **Тест «назови одним словом»:** если чёрный силуэт в игровом размере называют обычным зверем или птицей — брак; правильные ответы — «овечка на пружине», «домик на ножках», «камень с глазами». Проверяет отдельный агент, который видит только лист силуэтов с номерами (подписи-имена подсказали бы ответ).
2. Магия — в форме и поведении, не в эффектах: нельзя светящиеся контуры, искры, ауры, «галактику» внутри, руны, радуги, сердечки; нельзя фэнтези-штампы (кристальный олень, дух в маске, светящиеся глаза, многохвостая лиса, малыш-дракон, единорог, феникс, слайм, грибок с личиком, кит в небе и т. п.) и узнаваемое из чужих игр и мультфильмов. В каждом облике — рукотворная мелочь с историей (заплатка, обрывок нитки, скол, щербина).
3. «Бумажная аппликация»: 4–14 кусочков (у сложных — до 16), каждый — контур из 10–60 вручную расставленных точек (`P2`/`H2` → `Path2D`, кэш). Жёсткая тень (+0,8; +1,0) — у одного-двух верхних кусочков, у каждого облика своих. Без обводок и градиентов; `ellipse`/`arc` — только зрачки и точки меньше 3 ед.
4. Край «рваный», как у кочек: не меньше 8 надрезов, зубцов, фестонов или сколов по внешнему контуру, видимых в игровом размере (0,6–1,5 ед.). Гладкий «боб» — брак. Фактура — надрезами и отдельными кусочками. Деталь меньше 0,8 ед. в игровом размере не читается.
5. Главную черту преувеличь (нос звездорыла, приманка удильщика, тонкие ножки избушки). Короткие толстые лапки в игровом размере сливаются с телом — им нужны просветы.
6. Цвет «под луной»: 2 основных тона + акцент + тени (к `#1a1640` на 0,25–0,35); белый `#ecebe6`, чёрный `#1f1a22`, не `#000`. Свет — луна сверху слева, но кромка повторяет свою деталь, а не один серп на всех. Тёмным — холодная кромка `#5a5470`…`#6f6a8c`.
7. **Своё свечение** — только у пяти и только в одной детали: ростки Тихоходки, корешок Опят, кристаллы раскрытой Жеоды, грибок Удильщика, окошко Избушки (`ownGlow`); гаснет без заряда и в «Экономно». Тёплый светящийся цвет — только у светлячков.
8. **Шесть состояний у каждого свои:** покой (своё движение, не общая «пульсация»), моргание (у безликих — своё мелкое движение), взмах (своя анимация и длительность `flapK`), без заряда, подъём (`ly` < −0,3) и спуск (`ly` > 0,3) — позы полёта плавно по `poseK(a)`; в воздухе облик не «сидит». Смотрит туда, куда летит; в лавке, меню и на иконке — вправо.
9. Рамка: ноги в (0, 0); основная масса x ∈ [−22; 22], y ∈ [−46; 0]; выступы до y = −62 и x = ±32; в покое ничего ниже y = 4; в полёте свисающее — до y = +26. Анимированные контуры — из 2–4 ключевых контуров (`keyPath`, `keyMP`: смесь ступенями, каждая в кэше), в кадре — никаких новых `Path2D` без кэша.

## 5. Карта кода `index.html` (по именам; номера строк устаревают)

Весь JS — одна самовызывающаяся функция, разделы с заголовками `/* ===== Тихолесье · … ===== */`.

- **core:** константы (`WW` = 400 — ширина мира, `GRAV`, `VJ` — скорость прыжка, `M` = 10 ед. в метре, `STEP` = 1/120 с, `GIFT` = 100), помощники (`clamp`, `lerp`, `mulberry`, `hex`, `mixh`, `plural`, `wdx` — разница по x через склейку краёв), `FLOW`/`flowMult` (множитель ×1…×5), `ZONES` (5 зон: цвета, слои фона, `deco`, `beasts` — веса ворчунов), `zoneMix`, `SKINS` (12 обликов «Бестиария»: цена или `unlock`, `glow`, `flapK`, `trail: {k, every, life, at, col}`, `burst`, `trailName`), `UPS`/`UP` (усиления), `MDEF` (задания), `RANKS`, сохранение (`freshSave`, `migrateV1`, `SKIN_MAP_V3`, `migrateV2`, `applySave`, `loadSave`, `exportCode`, `importCode`, `persist`).
- **звук `Snd`:** `tone`, `hiss` (синтез), `setPad` (фоновый аккорд зоны), `fx` — все звуки (`bounce`, `rustle` — сухой лист, `vanish`, `coin`, `gift`, `stomp`, `hit`, `snapThread`, `shell`, `hoot`, `jellyBoing`, `sting`…), `selfTest`.
- **графика `Art`:** `glow` (кэш свечения), `poly`/`blob`/`spot`, платформы: `kochka` (не трогать), `pad`, `bouncer`, `leafPlat` (сухой лист), `ghost` (пунктирная капсула), `crystal`, общий кэш `plat`; фон: `bracket`, `shroom`, `bough`, `frond`, `fernFlower`, `druse`, `leafy`, `curl`, `islet`, `moon` (`MOON_SEAS`), `foliage` (6 силуэтов листвы), `cloud` (5 облаков); ворчуны: `beast` (спрайты по кадрам) и рисовальщики `BEAST_DRAW`; `bubble` (щит), `item` (находки), `bit` (11 видов частиц следа: `tMoss`, `tRot`, `tDew`, `tWool`, `tBark`, `tGrit`, `tRipple`, `tClod`, `tPaper`, `tScale`, `tSmoke`), `glowDash` (световая леска Удильщика, цвет параметром), `char` → `SKIN_ART[id]` (12 рисовальщиков: `tihohodka`, `opyata`, `rosyanka`, `baranets`, `beresten`, `zheoda`, `udilshchik`, `rybaluna`, `zvezdoryl`, `zmey`, `aspid`, `izbushka`; константы с префиксами `TH_`, `OP_`, `RO_`, `BA_`, `BE_`, `ZH_`, `UD_`, `RY_`, `ZV_`, `ZM_`, `AS_`, `IZ_`; помощники `P2`/`H2`, `MP`/`MPc` (несколько контуров одним путём), `TP` (штрих в кэше), `pc`/`pcs`, `inside`, `piv`, `comb`, `blip`, `poseK`, `flapU`, `keyPath`, `keyMP`, `ownGlow`, `rotP`), `anchor(sk, a)` — точка следа для позы (у Удильщика — грибок, у Избушки — труба; таблица `ANCHOR`), `setLite`.

- **интерфейс `UI`:** меню (`syncMenu`, `showMenu`, подарок дня: `giftReady`, `claimGift`), забег (`hint`, `tutorial`, `hud`, `toast`), пауза и итоги, лавка (`skinPreview` с частицами следа `trailBits` по раскладкам `TRAIL_LOOK`, у лески и дыма — от точки `Art.anchor`, `buyBar` со строкой «След: …», `renderShop`), задания (`renderQuests`), настройки, памятка (`LEGEND`, `LEG_MID`, `legendArt`).
- **запуск:** `resize`, `menuCamera`, касания и клавиатура, `frame` (главный цикл), `start`, `window.__tl`.

**Мир:** ширина 400 ед., y растёт вверх (на экране вниз, `Y(y)`). Пять зон: Грибная поляна (0 м), Папоротниковая чаща (600), Кристальные своды (1 600), Лунные кроны (3 000), Звёздная высь (5 000). Платформы: `static` — кочка, `moving`/`vmove` — плавучая, `bouncy` — гриб-батут, `puff` — сухой лист (один прыжок), `fake` — призрачная капсула, `phase` — мерцающий кристалл, `home` — вершина пня, `ground` — земля. Ворчуны (`game.beasts`, с 900 м, не в дзене): репейник, паук, жук-сторож, сыч, звёздная медуза.

## 6. Сохранение

- `localStorage`, ключ `tiholesye.save.v1` (ключ не меняется). JSON по схеме `freshSave()`, сейчас `v: 3`.
- Любые данные (хранилище, код переноса) идут через одну проверку `applySave()`. Старые схемы сначала проходят миграции по очереди: `migrateV1` (v1 → v2: облики 19.11 → 21.11, светлячки за убранные облики и следы, `refund`), затем `migrateV2` (v2 → v3: облики 21.11 → «Бестиарий» один к одному на той же ступени лавки по `SKIN_MAP_V3`, `renew` — один раз тост «Облики теперь новые…»). Тосты показывает `afterLoad()`.
- Код переноса: `TL1.` + base64 JSON (`exportCode`/`importCode`); принимаются `v` 1, 2 и 3.
- **Правило:** любая старая схема должна грузиться. Меняешь схему — повышай `v`, пиши `migrateVn` и вызывай его в начале `applySave` до проверки id. Прогресс игрока (светлячки, рекорды, задания, ранги, улучшения, настройки) не теряется никогда.

## 7. Что нельзя ломать

- Прогресс игроков (см. выше) и загрузку старых кодов переноса.
- Офлайн: `sw.js` и список `FILES`; имя кэша меняется при каждой выдаче.
- Физику, генерацию и сложность. Лес всегда проходим: рядом с одноразовой платформой всегда есть обычная кочка.
- Управление (свайп, края, наклон, клавиатура), паузу, второе дыхание, дзен, рывок кометы, задания, звук и музыку.
- Интерфейс «бумага и чернила»: переменные `:root`, срезы `--cut-a/b/c`, шрифты Underdog и Alegreya Sans, значки HUD.
- Особенности iPhone: кольца таймеров рисуются SVG-линией (с `transform: scaleX` Safari оставлял полосы); поле кода сохранения — шрифт не меньше 16 px и лечение окна после клавиатуры (`healViewport`, `afterKeyboard`); отступы safe-area.
- Скорость: 60 кадров на iPhone. Спрайты кэшируются (`Art.plat`, `simple`, `glow`), статичные контуры строятся один раз; листва у краёв «Лунных крон» рисуется кусками по 480 ед. (`wallChunk`), а не контурами каждый кадр — иначе кадр там тяжелее на 60%. Проверка: `tests.py speed`. Режим «Экономно» (`LITE`) убирает свечение и тяжёлые слои — всё новое тяжёлое он тоже выключает. Лимит частиц `game.parts` — 440.
